## About This Course

"Cloud architect" gets used loosely enough that developers eyeing the role often can't tell what it actually involves, or how it differs from the cloud developer title sitting next to it on the org chart.

This course draws that line clearly, then turns to the part that matters more: what it takes to actually get there, from a developer's starting point rather than a generic career-ladder template.

## What You'll Learn

- Telling apart the cloud architect role from other architecture roles — and specifically from the cloud developer role — by what each is actually accountable for
- Identifying the skills a developer already has that transfer, and the ones that still need building
- Building a career path into cloud architecture from wherever you're starting
- Building the reputation and influence that make the title stick, beyond the certification
- Getting oriented on the certification options worth considering for this specific role

## Who This Is For

Developers and engineers actively considering a move into cloud architecture, and the managers coaching someone toward it.
