## About the Book

*97 Things Every Information Security Professional Should Know* collects practical wisdom from security practitioners across the industry. Lee Atchison contributed to this volume, sharing perspectives on the intersection of security, cloud architecture, and application design.

A valuable reference for security professionals, architects, and engineers who need to understand security not just as a checklist but as a design discipline.
