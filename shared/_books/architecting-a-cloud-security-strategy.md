## About the Book

Moving to the cloud introduces a new set of security challenges that require deliberate architectural planning. *Architecting a Cloud Security Strategy* addresses the essential decisions technology leaders and architects must make to secure their cloud environments from the ground up.

## What You'll Learn

- How to design a cloud security architecture that scales with your organization
- Key decisions in identity management, network security, and data protection
- Frameworks for assessing and managing cloud security risk
- How to build security into your cloud migration and modernization efforts
