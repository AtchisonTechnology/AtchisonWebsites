# Projects

Work on the AtchisonWebsites monorepo is tracked in Linear (team
**Atchison Websites**, `WEB`), per the `linear-dev-process` skill. Each
issue's spec is its Linear description, and its status lives there too,
never in these files.

- **`services.md`** — the site registry and each site's dev port.
- **`WEB-<n>.md`** — old spec files for closed issues. Read-only history
  until the final cleanup. Don't create new ones.
- **`zArchive/`** — pre-Linear `Spec####`/`Bug####` files, kept as history.

Project parameters and overrides are declared in the repo root `CLAUDE.md`.
